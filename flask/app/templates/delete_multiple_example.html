DELETE文の実行例（複数条件）

このページでやること

  • 同じデータに対して AND / OR を入れ替え、削除結果の差を比較する
  • ORで想定より多く消える典型パターンを見て、削除前確認（SELECT）の重要性を理解する

前提：usersテーブル（同じデータで比較）

以下のデータを使って、ANDとORで結果がどう変わるか見ます。

実行例：同じ条件で AND / OR を入れ替えて比較

条件A：name = 'John'
条件B：age >= 30
この2つを AND と OR で入れ替えると、対象が大きく変わります。

① AND：両方満たす行だけ削除（対象が狭い）

-- まず削除対象を確認（安全） SELECT * FROM users WHERE name = 'John' AND age >= 30; -- 削除 DELETE FROM users WHERE name = 'John' AND age >= 30;

ポイント： OR にすると対象が一気に広がり、想定より多く消えることがよくあります。
だからこそ、DELETEの前に SELECT で「消える行」を必ず確認します。

注意例（実質エラー例）：ORで想定より多く消えるパターン

❌ よくある事故：「inactive の John だけ消したい」つもりが、Johnが全部消える
-- ❌ これだと「John」もしくは「inactive」のどちらかに当てはまれば削除される DELETE FROM users WHERE name = 'John' OR status = 'inactive';

この条件だと、John（activeでも対象） と inactive（John以外でも対象） が全部消えます。
「John かつ inactive」を狙うなら AND が必要です。

-- ✅ 本当に消したい条件（John かつ inactive） DELETE FROM users WHERE name = 'John' AND status = 'inactive';

対策： まず同じ条件でSELECTして「消える行」を目視確認する

SELECT * FROM users WHERE name = 'John' OR status = 'inactive';
✅ 安全な進め方： DELETE前の確認（SELECT）が習慣化できれば事故が減る
  • ① まず SELECT で対象確認
  • ② 対象が意図通りなら DELETE
  • ③ 変更後のテーブルで差を確認
