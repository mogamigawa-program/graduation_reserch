INSERT + SELECT文 実行例と注意点

実行例：まずSELECTだけ実行し「挿入される候補」を確認

まずは SELECT だけを実行して、どの行が挿入対象になるか確認します。
ここでは「18歳未満のユーザー」を temp_users にコピーする例です。

SELECT id, name FROM users WHERE age < 18;

（例）users テーブルの状態

users（コピー元）
idnameage
1佐藤太郎20
2鈴木花子17
3高橋一郎16
4田中次郎22
SELECT結果（＝挿入候補）
idname
2鈴木花子
3高橋一郎

緑が「WHERE条件に一致して挿入候補になった行」です。

実行例：INSERT + SELECTを実行し，挿入先テーブルが増えるのを確認

INSERT INTO temp_users (id, name) SELECT id, name FROM users WHERE age < 18;

（例）挿入前の temp_users

temp_users（挿入前）
idname
（データなし）

（例）挿入後の temp_users（青＝変化があった表 / 黄＝追加された行）

temp_users（挿入後）
idname
2鈴木花子
3高橋一郎

ポイント：
WHERE に一致した行数だけ、挿入先の行数が増えます（0件〜複数件）。

よくあるエラー（典型）

INSERT + SELECT が通らないときは、まず 「対応付け（INSERTの列） ⇔（SELECTの列）」 を確認します。
その上で、列数／型／主キー重複を疑うのが基本です。

❌ 列数不一致（INSERT列数 ≠ SELECT列数）
INSERT INTO temp_users (id, name) SELECT id, name, age FROM users;
対応付けチェック
挿入先（INSERT側） SELECT側 判定
ididOK
namenameOK
（なし）ageNG：余分

直し方： SELECTの列を2つにする（またはINSERT側を3列に揃える）

ターミナルでのエラーメッセージ例（英語 / MySQL）

mysql> INSERT INTO temp_users (id, name) SELECT id, name, age FROM users;
ERROR 1136 (21S01): Column count doesn't match value count at row 1
⚠ 型不一致（SELECTの値が挿入先の型に合わない）

例：挿入先の created_at が DATE なのに、SELECTで文字列（name）を持ってきている

INSERT INTO target_table (id, created_at) SELECT id, name FROM source_table;
対応付けチェック
挿入先（列 / 型） SELECT列 / 例 判定
id / INT id / 1 OK
created_at / DATE name / 'Taro' NG：型が合わない

直し方： DATE列には日付列をSELECTする（または変換して入れる）

ターミナルでのエラーメッセージ例（英語 / MySQL）

mysql> INSERT INTO target_table (id, created_at) SELECT id, name FROM source_table;
ERROR 1292 (22007): Incorrect date value: 'Taro' for column 'created_at' at row 1
❌ 主キー重複（移行先で衝突）

例：users.id が PRIMARY KEY のとき、すでに同じ id が存在すると失敗します。

INSERT INTO users (id, name) SELECT id, name FROM old_users;
移行先 users（すでに存在）
idname
1佐藤太郎
2鈴木花子
SELECT結果（old_users）
idname
2鈴木花子（旧）
3高橋一郎（旧）

どこが衝突？ id=2 が移行先にすでにある → PRIMARY KEY / UNIQUE違反

直し方： WHEREで除外する／重複しないIDにする／重複チェック（NOT EXISTSなど）を入れる

ターミナルでのエラーメッセージ例（英語 / MySQL）

mysql> INSERT INTO users (id, name) SELECT id, name FROM old_users;
ERROR 1062 (23000): Duplicate entry '2' for key 'PRIMARY'
覚えること：
  • まず SELECT 単体で「挿入候補」を確認
  • 次に INSERT + SELECT を実行し「挿入先が増えた」ことを確認
  • エラー時は「対応付け（INSERT列 ↔ SELECT列）」を最初にチェック

対策

  • 列の数と順番（対応付け）を確認する
  • まず SELECT だけ実行して、挿入される行を見てからINSERTする
  • 必要に応じて WHERE でデータを絞る
  • 主キー重複が心配なときは重複チェック（NOT EXISTS など）を検討する
