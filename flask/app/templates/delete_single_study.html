DELETE文（単数条件）の学習

このページで学ぶこと

  • DELETE FROM ... WHERE 条件; の基本形
  • 比較演算子（=, <, > など）と条件式の書き方
  • 削除前に SELECT で対象を確認する手順（安全な思考）

1. DELETE文の基本形

DELETE文は、テーブルから不要な行（レコード）を削除するSQLです。
単数条件では、WHEREに1つの条件を書いて削除対象を絞ります。

DELETE FROM テーブル名 WHERE 条件;
⚠ 注意： WHERE を書かないと、テーブルの全データが削除されます。
学習中でも、必ず WHERE を付けるクセをつけましょう。

2. 条件式と比較演算子

WHERE では「どの行を削除するか」を条件で指定します。
よく使う比較演算子は次の通りです。

よく使う比較演算子
演算子 意味 条件の例 読み方（例）
= 等しい id = 3 idが3の行
<> 等しくない age <> 20 年齢が20ではない行
< より小さい age < 18 年齢が18未満の行
<= 以下 age <= 10 年齢が10以下の行
> より大きい price > 1000 価格が1000より大きい行
>= 以上 score >= 80 点数が80以上の行

条件式は基本的に 「カラム名 演算子 値」 の形です。
文字列の場合は ' '（シングルクォート）で囲む点にも注意しましょう。

-- 数値の例 DELETE FROM employees WHERE id = 3; -- 文字列の例（文字列は ' ' で囲む） DELETE FROM employees WHERE name = 'Tanaka';

3. 安全な手順：DELETE前にSELECTで確認

DELETEは取り消しが難しい操作です。
そこで、安全に作業するために 「同じ条件でまずSELECT」 を実行し、削除対象を確認してからDELETEします。

-- ① まず削除対象を確認する（安全） SELECT * FROM employees WHERE id = 3; -- ② 削除対象が合っていれば削除する DELETE FROM employees WHERE id = 3;

考え方：「SELECTで出た行＝削除される行」
これを毎回確認するクセを付けると、事故（消しすぎ）を防げます。
