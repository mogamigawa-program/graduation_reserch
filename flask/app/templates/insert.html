INSERT文を学ぼう

INSERT文は、新しいデータをテーブルに追加するために使用されます。
テーブルの列に対応する値を指定することで、新しい行を挿入できます。

例えば、次のようにして test テーブルにデータを挿入します。

例:

INSERT INTO test (num, name) VALUES (1, 'John');
INSERT INTO test (name, num) VALUES ('John', 1);
