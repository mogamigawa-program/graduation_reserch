INSERT文の実行例

このページでやること

  • 1件挿入して、テーブル表示で行が増えることを確認する
  • 複数列挿入して、どの列に入ったかを確認する
  • 典型的なエラーについて「何を直せば通るか」をセットで理解する

前提：サンプルテーブル

以下のような students テーブルがあるとします。

CREATE TABLE students ( id INT PRIMARY KEY, name VARCHAR(100) NOT NULL, age INT );

id（PRIMARY KEY） は重複不可。name（NOT NULL） は必須です。

students テーブルの構造
列名 型 制約 入る値の例
id INT PRIMARY KEY（重複不可） 1, 2, 3...
name VARCHAR(100) NOT NULL（必須） '佐藤太郎'
age INT （なし） 20

実行例①：1件挿入 → 行が増えることを確認

INSERT INTO students (id, name, age) VALUES (1, '佐藤太郎', 20);

実行後、SELECT で確認します。

SELECT * FROM students;

青：変更があった表　／　黄：追加された行

実行前 → 実行後の変化
実行前（空） 実行後（1行追加）
idnameage
（データなし）

1佐藤太郎20

確認ポイント： id=1 の行が増えているか

実行例②：複数列挿入 → どの列に入ったかを確認

INSERT INTO students (name, age, id) VALUES ('鈴木花子', 19, 2);

よくあるエラー例（何を直せば通るか）

まずは「列数」／「値」／「制約」のどれが原因かを切り分けます。

典型エラーの原因と直し方
エラーの種類 原因（どれが原因？） 何を直せば通る？
列数と値数が一致しない 列数 列の数と値の数を一致させる
クオート忘れ（文字列） 値 文字列を ' ' で囲む
主キー重複（UNIQUE/PRIMARY KEY） 制約 重複しない値に変更する
NOT NULL違反 制約 NOT NULL の列に値を入れる

① 列数と値数が一致しない（列数が原因）

-- ❌ 列は3つなのに、値が2つしかない INSERT INTO students (id, name, age) VALUES (5, '山本一郎');

直し方： 値を3つにする（または列を2つにする）

-- ✅ 修正例 INSERT INTO students (id, name, age) VALUES (5, '山本一郎', 18);

ターミナルでのエラーメッセージ例（英語 / MySQL）

mysql> INSERT INTO students (id, name, age) VALUES (5, '山本一郎');
ERROR 1136 (21S01): Column count doesn't match value count at row 1

② クオート忘れ（値が原因）

-- ❌ 文字列なのにクオートがない（name は文字列） INSERT INTO students (id, name, age) VALUES (6, 佐々木陽子, 20);

直し方： 文字列を ' ' で囲む

-- ✅ 修正例 INSERT INTO students (id, name, age) VALUES (6, '佐々木陽子', 20);

ターミナルでのエラーメッセージ例（英語 / MySQL）

mysql> INSERT INTO students (id, name, age) VALUES (6, 佐々木陽子, 20);
ERROR 1054 (42S22): Unknown column '佐々木陽子' in 'field list'

③ 主キー重複（UNIQUE/PRIMARY KEY違反：制約が原因）

-- ❌ id=1 はすでに存在する想定 INSERT INTO students (id, name, age) VALUES (1, '山田次郎', 22);

直し方： 重複しない id に変える

-- ✅ 修正例 INSERT INTO students (id, name, age) VALUES (7, '山田次郎', 22);

ターミナルでのエラーメッセージ例（英語 / MySQL）

mysql> INSERT INTO students (id, name, age) VALUES (1, '山田次郎', 22);
ERROR 1062 (23000): Duplicate entry '1' for key 'PRIMARY'

④ NOT NULL違反（制約が原因）

-- ❌ name は NOT NULL なのに指定していない INSERT INTO students (id, age) VALUES (8, 20);

直し方： NOT NULL の列（ここでは name）に値を入れる

-- ✅ 修正例 INSERT INTO students (id, name, age) VALUES (8, '中村修', 20);

ターミナルでのエラーメッセージ例（英語 / MySQL）

mysql> INSERT INTO students (id, age) VALUES (8, 20);
ERROR 1364 (HY000): Field 'name' doesn't have a default value

※環境（SQLモード）によっては NOT NULL 関連の文言が少し変わることがあります。
