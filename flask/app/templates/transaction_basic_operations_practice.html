この演習でやること（比較が核）

  • パターンA： START TRANSACTION → UPDATE → COMMIT（変更が残る）
  • パターンB： START TRANSACTION → UPDATE → ROLLBACK（変更が戻る）
  • 同じ更新でも最終結果が変わることを、テーブルで確認する
注目ポイント： 「今の変更は確定した？（COMMITした？）」に常に注目してください。
※確定後（COMMIT後）は、通常 ROLLBACK では戻せません。
